# VUOO Bot v2

A página do VUOO Bot: a cabeça 3D animada, com o átomo, a tela de LEDs e os estados do companheiro.

- **Ao vivo:** https://eduardo-arcade-metrics.github.io/vuoo-bot-v2/
- **Motor:** `src/` (o pacote robot-heads, em canvas 2D)
- **Página:** `vuoo-bot/`
- **Especificação:** `docs/vuoo-bot.spec.ts`

```
pnpm install
pnpm dev       # http://localhost:5173/vuoo-bot-v2/
pnpm build     # gera vuoo-bot/dist
```
